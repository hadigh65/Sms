پروژه اندروید انتقال پیامک - نسخه اصلاح‌شده ساخت GitHub Actions

عملکرد:
- شماره مقصد و عبارت یا بخشی از متن پیامک را در برنامه وارد و ذخیره کنید.
- فقط پیامک‌هایی که متنشان شامل عبارت ثبت‌شده باشد، منتقل می‌شوند.
- متن کامل پیامک همراه شماره فرستنده به شماره مقصد ارسال می‌شود.

ساخت APK:
1) محتویات این ZIP را در ریشه مخزن GitHub بارگذاری و فایل‌های قبلی را جایگزین کنید.
2) مطمئن شوید پوشه مخفی .github نیز بارگذاری شده است.
3) به Actions بروید؛ workflow با push اجرا می‌شود یا از Run workflow اجرا کنید.
4) پس از موفقیت، از بخش Artifacts فایل SmsForwarder-debug-apk را دانلود کنید.
5) ZIP دانلودشده را باز کنید و app-debug.apk را نصب کنید.

این نسخه برای کار با رضایت صاحب گوشی طراحی شده و به مجوزهای دریافت و ارسال SMS نیاز دارد.
هزینه پیامک ارسالی طبق تعرفه سیم‌کارت گوشی است. خاموش بودن صفحه به‌تنهایی مانع دریافت پیامک نیست، اما تنظیمات محدودکننده باتری سازنده گوشی می‌تواند اثر بگذارد.
این پروژه هنوز روی دستگاه واقعی شما آزمایش نشده است؛ موفقیت ساخت را از نتیجه GitHub Actions بررسی کنید.
